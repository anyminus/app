# Changelog

## 0.1.3
- Reorder playlist and favorite tracks by dragging the dedicated handle in edit mode (mouse, touch and keyboard); persist the new order.

## 0.1.2
- Independent mute by tapping music or vocal icons; disabled sliders while muted, restore previous volume on unmute.
- Persist mute preferences across player and settings; fix ambiguous playlist test locator.

## 0.1.1
- Hidden playlist editor, enabled by five profile taps within four seconds and hidden again on demand.
- Create, rename and delete playlists; search, add and remove tracks without duplicates.
- Local playlist changes update the home collections; persisted per browser, no backend changes.

## 0.1.0
- Mobile-first prototype with search, home, favorites, artist and track pages, history, profile, settings, sharing and mock preparation.
- Bottom karaoke dock, synchronized synthetic test signals and independent volume controls.
- Storybook and automated checks; GitHub Pages workflow.
