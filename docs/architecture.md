# Frontend boundaries

Source of truth: anyminus/app. anyminus/core is read-only. This static prototype uses fictional catalog metadata, authored demo lyrics and synthetic audio. No requests to core, no server credentials, no copied private source. Production adapter must use the documented API and authorization boundary; verify CORS/same-origin deployment before enabling it. Search contract: GET /v1/search; library GET/POST /v1/library; media ticket POST /v1/playback-sessions/{id}/media-ticket; these are only contract notes, no live verification. Artist profiles and sharing currently resolve to local mock IDs. Browser demo audio is not a substitute for core's production player or recorded vocal stems. No backend code or data is modified.

Design system: semantic CSS variables for dark/light themes, reusable artwork, mixer, icon button, track row. Storybook catalog is served at /app/storybook/. Hash routing permits deep links without server rewrite. Independent volume preferences use 0–100%; default music 100, artist vocal 15. Shared clock, two gain nodes. The vocal guide is synthesized, not a real artist recording. No audio is uploaded. Production synchronization and device compatibility require further testing.
