# Face mask prototype (0.5.83 base)
Branch: prototype/face-masks. The main app and backend are untouched.
Select “Маска: ноты (β)” in video preview. Both notes follow the detected pupils, scale with their distance and rotate with the eye line. The existing recording canvas receives the effect before the lyrics/branding, so the file contains the same mask. No extra camera permission, no audio graph changes, no frame uploads.
Implementation: classic randomized decision trees (not neural networks). Pico.js/lploc.js pinned to afffa50ec4134a47005f2cbf8112eaa69f65f37e; module scope and numeric median fixes only. Face finder from nenadmarkus/pico c2e81f9d23cc11d1a612fd21e4f9de0921a5d0d9; pupil cascade from esimov/pigo 9ad5f2b5ee2104f6dc7aa81a40ca7ccf539fc2ea (same binary layout). Build script verifies Git blob hashes and writes local static assets; browser downloads only from the app origin and only on selection. Worker receives downsampled pixels (long side 320, max 10 Hz, one in flight); canvas uses existing recording cadence. Missing or stale face hides the mask, worker error falls back to ordinary recording. Worker disposed on disabling or leaving capture.
Upstream code and model repositories: see src/vendor/NOTICES.md.
Acceptance: Safari iPhone, choose mask, move/tilt head, move closer, briefly leave frame; record 30–60 seconds, inspect saved MP4, compare audio quality, sync, thermal load to mask-off. Test poor lighting and eyeglasses. Strong turns and eye occlusion are limitations; notes are decorative, not an anonymization guarantee. Verify preview and export, lyrics on/off, failure fallback and worker cleanup.
